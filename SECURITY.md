# Kebijakan Keamanan (Security Policy)

## Pelaporan Kerentanan Keamanan

Jika Anda menemukan celah atau kerentanan keamanan pada repositori Dongnime, mohon untuk **tidak** melaporkannya secara publik melalui GitHub Issues.

Silakan kirimkan laporan secara langsung melalui:
- **GitHub Private Vulnerability Reporting** pada tab [Security](../../security/advisories/new) di repositori ini.

Mohon sertakan:
1. Deskripsi kerentanan dan potensi dampaknya.
2. Langkah-langkah untuk mereproduksi celah keamanan (*Proof of Concept*).
3. Rekomendasi perbaikan jika tersedia.

Kami berkomitmen untuk meninjau dan merespons setiap laporan secara kooperatif dan bertanggung jawab.
